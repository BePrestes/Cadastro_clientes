Sistema de Cadastro de Clientes

Este projeto foi desenvolvido com o objetivo de colocar em prática os conhecimentos adquiridos durante meus estudos em **PHP** e **PostgreSQL**.

A ideia foi criar um sistema simples, mas funcional, que realizasse as operações básicas de um CRUD (Create, Read, Update e Delete), simulando um cenário encontrado em aplicações reais.

---

##  Tecnologias utilizadas

- PHP
- PostgreSQL
- HTML5
- CSS3
- JavaScript

---

##  Funcionalidades

- Cadastro de clientes
- Listagem de clientes
- Edição de informações
- Exclusão de registros
- Validação de formulário
- Confirmação antes da exclusão

Durante o desenvolvimento procurei aplicar conceitos importantes para o desenvolvimento backend, como:

- Organização de arquivos
- Conexão com banco utilizando PDO
- Prepared Statements
- Operações CRUD
- Manipulação de formulários
- Validação de dados
- Integração entre PHP e PostgreSQL
- Estruturação de um pequeno sistema web

---

##  Objetivo

Este projeto faz parte da minha jornada de aprendizado em desenvolvimento web.

Meu foco foi compreender como funciona o fluxo completo de uma aplicação backend, desde o envio de um formulário até o armazenamento e manipulação das informações no banco de dados.

Embora seja um projeto simples, ele representa um passo importante na consolidação dos meus conhecimentos em PHP e banco de dados relacionais.
